---
title: Managing draft branches
description: Dashboard view of your open branches, discarding a draft, and reverting to a previous revision.
---

Your active branches live in the **Branches** section of **Policy lifecycle → Policy branches**. This view shows every branch in all states.

## Branch states

| State | Meaning |
|---|---|
| `DRAFT` | You're still authoring; not yet submitted |
| `IN_REVIEW` | Submitted and awaiting reviewer action |
| `APPROVED` | All reviews passed; bundle being generated |
| `PUBLISHED` | Live — rules are in agents' bundles |
| `REJECTED` | Reviewer returned the branch for revision |
| `ABANDONED` | You discarded this branch |

## Saving rule edits

1. Open a rule, make your changes, then choose **Update working draft** (or **Add to draft** for a new rule).
2. The authoring page displays **Unsaved changes**. You can test the working draft before saving.
3. Enter a change summary and choose **Save draft**. This saves the current rules as a new revision.
4. Continue to **Review & publish** when the draft is ready for approval.

Saving a draft does not publish it or change what agents enforce. If saving fails, your edits remain in the editor for retry. Closing a rule with un-applied edits asks whether to discard them. The page warns before unloading with unsaved changes; supported browsers also warn on client-side Back/Forward navigation.

**Advanced metadata** contains the source path. It is optional for normal editing. **Discard unsaved changes** restores the loaded baseline after confirmation.

## Filtering the list

Use the workspace page dropdowns to switch contexts. Sort the branches table to locate recently active branches.

## Viewing a branch

Click any branch row in the table to open the **Branch Inspector** slideout panel. This panel displays the branch status, scope, author, active revision, and provides quick navigation actions to author rules or review changes.

## Discarding a draft

To permanently delete a branch you no longer need:

1. Open the branch inspector slideout panel by clicking its row.
2. Scroll to the **Danger zone** section at the bottom.
3. Type the branch name in the confirmation text box.
4. Click the **Delete branch permanently** button.

## Duplicating a branch

To start a new branch based on an existing one, you can import or duplicate the policy rules via the workspace Policy Import panel.

## Reverting to a previous revision

Published branches track every revision. To see a branch's history:

1. Click the branch row to open the inspector, then click **Review & Publish**.
2. Scroll down on the approvals page to view the **Revisions** history list.

Each revision shows the date, who submitted it, and which rules changed. You can perform rollbacks to earlier revisions directly. Connected agents pick up the rollbacks on their next sync interval.
