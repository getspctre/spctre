Spctre is open-core. Self-hosted deployments default to the OSS tier. Set `SPCTRE_PLAN` to unlock higher-tier features.

## Tiers

| Tier | `SPCTRE_PLAN` value | Typical use case |
|---|---|---|
| OSS | `oss` (default) | Self-hosted, open-source deployments |
| Cloud | `cloud` | Managed cloud; SLA-backed escalations, archival, SIEM |
| Business | `business` | Compliance exports, full-history simulation |
| Enterprise | `enterprise` | Multi-tenant isolation, SAML/SCIM, custom RBAC |

## Setting the plan

```bash
SPCTRE_PLAN=cloud   # or: business, enterprise
```

Set this on the web app and worker processes. The value is read at startup; restart both services after changing it.

<Callout type="info">
  `SPCTRE_PLAN` is not validated against a license key in OSS builds — it is an honour-system gate. Cloud and Enterprise deployments enforce the plan via a signed license token set by Spctre.
</Callout>

## Feature flag API

For server-side feature checks in custom integrations:

```ts
import { isFeatureEnabledForPlan, normalizeSpctrePlan } from "@/lib/feature-flags";

const plan = normalizeSpctrePlan(process.env.SPCTRE_PLAN);
if (isFeatureEnabledForPlan("siemEventStreaming", plan)) {
  // SIEM is active
}
```
