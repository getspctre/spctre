## Core

| Variable | Type | Default | Description |
|---|---|---|---|
| `DATABASE_URL` | string | — | PostgreSQL connection string (required) |
| `DATABASE_OWNER_URL` | string | — | Owner connection for multi-tenant schemas |
| `NODE_ENV` | `production` \| `development` | `development` | Runtime environment |
| `SPCTRE_RUNTIME_MODE` | `production` \| `development` | `development` locally | Runtime security policy. Required when `NODE_ENV=production`; production-like deployments should set `production` explicitly. |
| `SPCTRE_APP_URL` | string | — | Public URL of the control plane web app |
| `SPCTRE_ENV` | string | `development` | Deployment environment name |
| `SPCTRE_DEFAULT_TENANT_ID` | string | — | Default tenant for an explicitly declared single-tenant deployment; requires `SPCTRE_SINGLE_TENANT_MODE=true`. |
| `SPCTRE_SINGLE_TENANT_MODE` | boolean | `false` | Allows `SPCTRE_DEFAULT_TENANT_ID` to bind background work. Do not enable in a multi-tenant deployment. |
| `SPCTRE_PLAN` | `oss` \| `cloud` \| `business` \| `enterprise` | `oss` | Plan tier; controls feature gating for SAML, SCIM, simulation, HITL, archival, and SIEM features. See [Plan tiers](/help-docs/developer/reference/plan-tiers). |

## Security

| Variable | Type | Default | Description |
|---|---|---|---|
| `SPCTRE_ALLOWED_SOURCE_IPS` | comma-separated | — | IP allowlist for all requests. Evaluated against the client address derived from `x-forwarded-for`; set `SPCTRE_TRUSTED_PROXY_HOPS` alongside it or the allowlist can be bypassed by a forged header. |
| `SPCTRE_TRUSTED_PROXY_HOPS` | integer | — | Number of proxies in front of this service that append to `x-forwarded-for`. With `N` declared, the client address is the Nth entry from the right and anything to its left is ignored as caller-supplied. Unset trusts the leftmost entry, which the caller controls. |
| `SPCTRE_ALLOWED_CONNECTORS` | comma-separated | — | Permitted connector IDs |
| `SPCTRE_ALLOWED_TOOLS` | comma-separated | — | Permitted tool names |
| `SPCTRE_CREDENTIAL_ENCRYPTION_KEY` | string | — | Passphrase for `pgp_sym_encrypt`/`pgp_sym_decrypt`; encrypts alerting integration credentials and SIEM stream secrets at rest. Required when alerting integrations or SIEM streams are configured. |

|---|---|---|---|
| `SPCTRE_API_TOKEN` | string | — | MCP server STDIO: access token for control plane authentication |

| `SPCTRE_MCP_AUDIT_SEAL_SECRET` | string | — | Signing secret for MCP audit seals |
