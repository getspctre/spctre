This section walks you from a fresh Spctre workspace to a production-ready governed agent.

## What you'll cover

- **[Quick start](/help-docs/developer/getting-started/quick-start)** — Connect an agent and make your first evidence call in under 5 minutes.
- **[Core concepts](/help-docs/developer/getting-started/core-concepts)** — Policies, branches, packs, evidence, and the policy loop.
- **[Onboarding](/help-docs/developer/getting-started/onboarding)** — Full onboarding guide: CLI tokens, workspace setup, and first bundle publish.

## Before you start

You need:

- A Spctre workspace (created at your control plane URL or on [spctre.dev](https://spctre.dev))
- The Spctre CLI: `npm install -g @spctre/cli`
- One of the [supported agent frameworks](/help-docs/developer/agents/agents) or a custom agent that can make HTTP calls
