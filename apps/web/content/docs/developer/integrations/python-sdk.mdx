<Callout type="info">
  Install the supported Python SDK with `pip install spctre-sdk`. It requires Python 3.11 or later.
</Callout>

Python agents have three integration paths: the **framework adapter** (zero-code, recommended for supported frameworks), the supported **Python SDK**, or **direct REST calls** via `httpx` or `requests`.

## Framework adapter (recommended)

For CrewAI, LangChain, LangGraph, AutoGen, Google ADK, AWS Bedrock, Azure AI, and Gemini agents, the CLI generates a `sitecustomize.py` adapter that patches framework internals — no SDK calls in your agent code.

```bash
spctre init --workspace <slug> --agent <agent-id>
spctre watch --framework crewai   # replace with your framework
```

Run your agent through the Spctre wrapper to activate the adapter:

```bash
.spctre/spctre-python my_agent.py
```

See [Framework adapters](/help-docs/ai-agents/adapters/framework-adapters) for the full list of supported frameworks and how the adapter works.

## Python SDK

Install the supported client:

```bash
pip install spctre-sdk
```

Create a client with your control-plane origin and service token. The client
adds `/api/v1` automatically; passing a URL that already ends in `/api/v1` is
also supported.

```python
import os

from spctre import SpctreClient

client = SpctreClient(
    base_url=os.environ["SPCTRE_API_URL"],
    token=os.environ["SPCTRE_API_TOKEN"],
)
```

Use the domain facades such as `client.gateway`, `client.evidence`, and
`client.trust`; request and response models are available from `spctre.models`.
See the [SDK README](https://github.com/getspctre/spctre/tree/main/packages/sdk-python)
for the supported operations and complete examples.

## Direct REST — submitting evidence

For custom frameworks or agents that don't use a supported adapter, call the evidence endpoint directly:

```python
import httpx, os

client = httpx.AsyncClient(
    base_url=os.environ["SPCTRE_API_URL"],
    headers={"Authorization": f"Bearer {os.environ['SPCTRE_API_TOKEN']}"},
)

await client.post("/api/v1/evidence", json={
    "decisionId": "dec_01j9xk2f",
    "agentId": "payments-agent",
    "connector": "stripe",
    "action": "charge",
    "environment": "production",
    "status": "ALLOW",
    "reason": "Amount within approved tier",
    "runtimeTarget": {"stack": "CUSTOM"},
    "policyRefs": ["br_01j9xk"],
    "artifactHash": "sha256:abc123…",
    "policyContext": [
        {
            "scope": "CONNECTOR",
            "branchId": "br_01j9xk",
            "revisionId": "rev_99",
            "artifactHash": "sha256:abc123…",
        }
    ],
    "sessionId": "sess_abc123",
})
```

## Token management

The CLI handles token rotation automatically when you run `spctre watch`. For long-running Python processes that call the REST API directly, read the token from `.spctre/spctre-config.json` and re-read it when the access token expires (every hour):

```python
import json, pathlib

def load_token() -> str:
    config = json.loads(pathlib.Path(".spctre/spctre-config.json").read_text())
    return config["accessToken"]
```

Or set `SPCTRE_API_TOKEN` to a long-lived service token issued from the control plane.

## Maintaining the SDK

The SDK's private generated client is checked into the repository. Only SDK
maintainers need to regenerate it after changing the OpenAPI specification:

```bash
pnpm generate:python-sdk
```

This runs the pinned `openapi-python-client` generator and updates
`packages/sdk-python/spctre/_generated`. The public `spctre-sdk` distribution
wraps that generated layer with the supported `SpctreClient` facade.
