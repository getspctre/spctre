## spctre init

Connect an agent to Spctre and write `.spctre/config.json`.

```bash
spctre init [options]
```

| Flag | Description |
|---|---|
| `-w`, `--workspace` | Workspace slug (default: `default`) |
| `-a`, `--agent` | Agent ID (default: `solo-agent`) |
| `-e`, `--environment` | Environment name (default: `production`) |
| `-o`, `--output` | Output path for config file (default: `spctre-policy.json`) |
| `-u`, `--url` | Control plane URL (default: `http://localhost:3000`) |
| `-t`, `--timeout` | Approval timeout in seconds (default: `60`) |
| `--token` | Skip browser flow; use this service token |
| `--device` | Use RFC 8628 device code flow (headless) |
| `--no-open` | Don't open the browser automatically |

## spctre bundle export

Export the latest published bundle to a non-AGT target artifact and manifest sidecar.

```bash
spctre bundle export --format opa-bundle --output spctre-opa-bundle.json
```

| Flag | Description |
|---|---|
| `--format` | Export target: `spctre-json`, `opa-rego`, `opa-bundle`, `cedar`, or `mcp-proxy-config` |
| `-w`, `--workspace` | Workspace ID |
| `-k`, `--key` | Control plane API key |
| `-o`, `--output` | Artifact output path |
| `--manifest-output` | Manifest output path (default: `<output>.manifest.json`) |
| `-u`, `--url` | Control plane URL |
| `-q`, `--quiet` | Suppress output except errors |

The command exits non-zero when the target export is blocked by semantic warnings that would weaken enforcement.

## spctre bundle run-verifiers

Run target-native verifier tools (`opa check`, `cedar validate`, etc.) against a local export artifact. Requires the relevant tool to be on `PATH`.

```bash
spctre bundle run-verifiers --artifact spctre-opa-bundle.json --manifest spctre-opa-bundle.json.manifest.json
```

| Flag | Required | Description |
|---|---|---|
| `--artifact` | Yes | Export artifact path |
| `--manifest` | Yes | Manifest sidecar path |
| `--output` | No | Output format: `text` (default) or `json` |
| `--allow-missing-tools` | No | Treat missing verifier tools as skipped instead of failing (useful in local dev where not all tools are installed) |

Exits non-zero if any verifier tool reports an error. Use `--allow-missing-tools` in CI environments where only a subset of target verifiers are installed.

## spctre watch

Continuously sync the policy bundle and optionally install a framework adapter.

```bash
spctre watch [options]
```

| Flag | Description |
|---|---|
| `--framework` | Framework adapter: `crewai`, `langchain`, `langgraph`, `openai-agents`, `autogen`, `google-adk`, `bedrock`, `azure-ai`, `gemini`, `strands`, `notion-worker`, `antigravity-sdk`, `claude-agent-sdk`, `omnigent`, or `local-custom` |
| `-w`, `--workspace` | Workspace ID |
| `-k`, `--key` | Control plane API key |
| `-o`, `--output` | Bundle output path |
| `-u`, `--url` | Control plane URL |
| `-i`, `--interval` | Sync interval in seconds (default: `30`) |
| `--heartbeat` | Also send a heartbeat on each sync cycle |
| `--heartbeat-interval` | Heartbeat interval in seconds (default: same as `--interval`) |
| `--shadow` | Observe-only mode: evaluate but never block; log to `.spctre/shadow-log.jsonl` |
| `-q`, `--quiet` | Suppress output except on changes and errors |

For Notion Workers, see [Notion integration](/help-docs/developer/integrations/notion).

## spctre status

Show current CLI configuration and agent connection state.

```bash
spctre status [--check] [--output <format>]
```

| Flag | Description |
|---|---|
| `--check` | Ping the control plane to verify token and connectivity; exits non-zero if not connected |
| `--output` | Output format: `text` (default) or `json` |

Without `--check`, `status` prints the local config (workspace, agent ID, environment, token expiry) and exits zero even if the token is expired or the control plane is unreachable.

With `--check`, it performs a live ping and exits:

| Exit code | Meaning |
|---|---|
| `0` | Token valid, control plane reachable, bundle in sync |
| `1` | Token expired or invalid |
| `2` | Control plane unreachable |
| `3` | Bundle out of date (heartbeat reports stale artifact hash) |

**CI health-check step:**

```yaml
- name: Verify Spctre agent connectivity
  run: spctre status --check
  env:
    SPCTRE_API_TOKEN: ${{ secrets.SPCTRE_API_TOKEN }}
```

Add `--output json` to parse results in a script:

```bash
spctre status --check --output json | jq '.connected'
```

## spctre policy import

Create or update a policy branch from a source-controlled policy file. This is
an operator/CI command: it drafts a revision but never approves or publishes
it.

```bash
spctre policy import policies/payments.yaml \
  --connector stripe --scope CONNECTOR \
  --key "$SPCTRE_OPERATOR_TOKEN" --url https://app.spctre.dev
```

| Flag | Description |
|---|---|
| `-b`, `--branch` | Branch name; defaults to the connector, then the file name |
| `-c`, `--connector` | Connector ID; selects `CONNECTOR` scope unless `--scope` is given |
| `--scope` | `WORKSPACE`, `CONNECTOR`, `ENVIRONMENT`, or `ORGANIZATION` |
| `-e`, `--environment` | Environment; required for `ENVIRONMENT` scope |
| `-w`, `--workspace` | Advisory workspace assertion; the token workspace is authoritative |
| `--source-path` | Provenance path recorded with the revision |
| `--source-format` | Override dialect detection: `AGT_YAML`, `OPA_REGO`, or `CEDAR` |
| `--dry-run` | Convert and validate without creating a draft revision |
| `--offline` | Convert locally without a key, network request, or remote revision |
| `-o`, `--output` | In offline mode, write the generated AGT-compatible JSON document |
| `--report` | In offline mode, write the conversion report JSON |
| `-k`, `--key` | Service key with the admin-issued `policy:import` scope |
| `-u`, `--url` | Control plane URL |
| `--format` | Output format: `text` (default) or `json` |

See [Importing policies](/help-docs/developer/policies/importing) for the
source format and idempotency behavior.

For an explicitly local-only conversion, use:

```bash
spctre policy convert policies/github.cedar --output policy.json --report conversion.json
```

This runs the same supported-subset translator but cannot perform
control-plane authorization, review, publication, or runtime-context checks.

## spctre blueprint import

Create or update an agent Blueprint from a source-controlled YAML or JSON
file. This is also an operator/CI command: it creates an unapproved draft and
never approves or publishes it.

```bash
spctre blueprint import blueprints/payments-agent.yaml \
  --key "$SPCTRE_OPERATOR_TOKEN" --url https://app.spctre.dev
```

| Flag | Description |
|---|---|
| `-w`, `--workspace` | Advisory workspace assertion; the token workspace is authoritative |
| `--source-path` | Provenance path recorded with the revision |
| `--dry-run` | Validate the source locally without contacting the control plane |
| `-k`, `--key` | Service key with the admin-issued `blueprint:import` scope |
| `-u`, `--url` | Control plane URL |
| `--format` | Output format: `text` (default) or `json` |

See [Agent Blueprints](/help-docs/developer/agents/blueprints) for the source
format, the published-policy binding, and review workflow.
