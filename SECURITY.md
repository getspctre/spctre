# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities privately by emailing:

```text
security@spctre.dev
```

Include the affected package, route, CLI command, or deployment component, plus
reproduction steps when possible. Please do not disclose the issue publicly
until a fix is available.

## Response and Patch SLA

Spctre targets acknowledgement within 3 business days. For confirmed
vulnerabilities, Spctre targets a patch or mitigation within 90 days, with
critical issues prioritized for faster remediation.

## Advisory Workflow

Security fixes should be coordinated through GitHub Security Advisories so CVEs
and patched versions flow back to package consumers. Maintainers should publish
advisories for affected npm packages and deployment images when applicable.
