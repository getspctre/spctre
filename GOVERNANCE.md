# Governance

Spctre is maintained by the repository maintainers named in
[`.github/CODEOWNERS`](.github/CODEOWNERS). Maintainers are responsible for
reviewing contributions, enforcing repository policies, publishing OSS
releases, and responding to security reports.

## Decision making

Design and product decisions begin in GitHub Issues or Discussions. A proposed
change becomes accepted when a maintainer approves the corresponding pull
request and the required checks pass. Maintainers may request design context,
tests, documentation, or a narrower change before approving a contribution.

## Maintainer changes

Repository owners add or remove maintainers through GitHub organization access
and update `CODEOWNERS` in the same pull request when ownership changes.

## Escalation

For conduct concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). For
security concerns, follow [SECURITY.md](SECURITY.md).
